# Automação Web com Python e Selenium

Projeto de automação web desenvolvido em Python utilizando Selenium durante meus os estudos de automação baseado no conteúdo/tutorial da Hashtag Treinamentos.

O objetivo deste projeto é automatizar o processo de acesso ao minicurso de Python da Hashtag Treinamentos, realizando automaticamente o cadastro e o acesso ao conteúdo.

# O que o projeto faz

A automação realiza as seguintes etapas:

1 - Abre o navegador Google Chrome.
2 - Acessa a página do minicurso.
3 - Localiza e clica no botão de cadastro.
4 - Preenche o primeiro nome.
5 - Preenche o endereço de e-mail.
6 - Preenche o número de WhatsApp.
7 - Envia o formulário de cadastro.
8 - Acessa a página seguinte.
0 - Clica no botão para acessar o conteúdo do minicurso.

Ao final, o navegador permanece aberto para a visualização do resultado.

# Tecnologias

1 - Python
2 - Selenium
3 - WebDriver Manager
4 - Google Chrome
